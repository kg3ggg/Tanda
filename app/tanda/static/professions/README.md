# Изображения для профессий

Здесь должны находиться изображения для каждой профессии.

## Соответствие профессий и файлов:

| Профессия | Имя файла | Описание |
|-----------|-----------|---------|
| Технологии и системы управления робототехникой | `robotics.jpg` | Инженер с роботом |
| Правоведение | `law.jpg` | Юрист с кодексом |
| Преподавание в начальных классах | `teaching.jpg` | Учитель у доски |
| Финансы по отраслям | `finance.jpg` | Финансист с графиками |
| Электроснабжение | `power.jpg` | Инженер-энергетик |
| Моделирование швейных изделий | `fashion.jpg` | Швея с платьем |
| Налоги и налогообложение | `tax.jpg` | Налоговый консультант |
| Ремонт автомобилей | `auto.jpg` | Автомеханик |
| Строительство и сооружения | `construction.jpg` | Строитель на стройке |
| Менеджмент с китайским языком | `management.jpg` | Менеджер с картой мира |

## Как добавить изображения:

1. **Скачай изображения** — они находятся в прикреплениях к сообщению
2. **Переименуй файлы** согласно таблице выше
3. **Помести в эту папку** (`tanda/static/professions/`)
4. **Запусти команду** в терминале:
   ```bash
   python manage.py link_profession_images
   ```

## Формат файлов:

- Рекомендуемый формат: JPG, PNG
- Рекомендуемый размер: 400x300px - 800x600px
- Максимальный размер: не более 5MB

После выполнения этих шагов все профессии будут иметь изображения!
